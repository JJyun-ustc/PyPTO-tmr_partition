# 流式机制与本轮实际执行范围

## 可见信息与任务所有权

O 为本轮任务发布独立、生命周期内不复用的元数据记录。“后继已提交”和“依赖登记完成”分别取得单调递增的 epoch。S 在读取后继之前捕获已发布 epoch，只接受不晚于该时点的记录。未知、登记中、预算内可用、后继索引溢出和入度超预算分别编码；未知执行位置使用中性局部性。

每类纯资源有无偏好、偏好 0、偏好 1 三个逻辑队列。两个偏好队列使用独立有界存储，不复用旧 automatic 绑侧队列。窥视得到队列 ticket 和元数据索引，再复核 sequence 与 dequeue 位置。最终领取必须先成功执行该队头 CAS，再通过原有整任务/block 范围 CAS；元数据与任务代次也须匹配。看到队头或空槽不等于取得所有权。

本轮板上分支在原普通调度机会检查三个队头，按最早 ready 时间领取。scope、同步、严格绑侧、谓词、DUMMY、提前 staging 和 MIX 仍服从原协议。新策略的目标仅为普通、未领 block 的单 block AIC/AIV；其他任务继续占用实际资源 tracker。

**本构建没有准入任何局部性类别，因此所有偏好都是中性。** 板上实际测到了元数据发布、安全窥视和 B 公共领取开销，但没有偏好入队、替代动作比较、资源日历改派或学习残差。C/D 是与 B 共用路径的受保护占位组。分析式已在 CPU 参考实现和 native 单元测试中实现，但**尚未接入主动 NPU 派发**。这些结果不能证明 C/D 有效或无效。

## CPU/native 两动作模型

从同一个快照比较“先 U”与“先 T”，两种动作都处理全部候选。每放一个任务就更新兼容槽释放时间。后续领取保持工作守恒：选最早可开始的兼容槽，不能为了等更快的一侧而让当前空槽闲置。第一个动作必须有真实可立即使用的槽。

只有当时已登记完整、且满足固定索引和入度预算的汇合才可替换它所支配的任务完成终点；其他竞争任务仍进入最大值。两个局部最大终点的差值才是净收益。已发生的依赖处理不重复收费。剩余时间取“历史跨度仍大于已运行时间”的尾部条件中位数。

准入门槛要求至少 30 个独立动作标定时段，预测收益大于高估误差、额外开销和 0.5 µs。当前真实放置实验尚未提供完整两动作干预标签，局部性差异也未稳定，因此准入表为空。CPU 合成标签不能补成真实板上反事实，本轮没有据此启动或准入神经模型。

## 实验能够回答的范围

板上四个菱形用例验证 Shared 下提前/延后提交的可见性，以及快慢兄弟分支 FIN 顺序。CPU“相同前缀、不同未来”验证不读未来；改变动作后重新计算资源释放和后继 ready。其完美时间先验仅用于验证，不能作为真实预测误差。

重用微基准两条件使用相同 GM 地址，每个条件完成后再继续。真实 Qwen 标定只控制每层第一块 33→34 的生产者/消费者侧别，37 个计算 kernel 不变。分析匹配实际 AIV 核、S 线程，并另做资源占用匹配；这是 decode 背景下的放置组合差异，不能单独归因给硬件传输。

AICore 区间是 ACK 后、kernel 前至 kernel 后、FIN 前；CPU 发布/提升至 FIN 观察的不同代理保留各自口径。选定记录在共同 50 MHz 计数尺度上满足因果时间不等式。每次带 profiling 的运行都与独立完整基线逐任务核对 block 数。

正式实验能量出 B 相对 Shared 的元数据与队头探测基础设施开销，不能把它全部归因于队列操作，因为 B 还开启任务记录登记。主动 C/D 收益、汇合引起的排序改变，以及 QKV 相对线性的净收益，本轮都没有测得。这些是明确缺口。
